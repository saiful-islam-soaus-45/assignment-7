#  KeenKeeper

KeenKeeper is a smart personal relationship management tool designed to help you stay consistently connected with your friends, family, and professional network. Never lose touch with the people who matter most!

---

##  Description

In the hustle and bustle of daily life, it's easy to forget when we last spoke to a close friend or colleague. **KeenKeeper** solves this problem by tracking your interactions and setting customized communication goals. It monitors the days passed since your last contact, sends alerts when a catch-up is overdue, and provides seamless one-click check-ins via Call, Text, or Video. It also visualizes your interaction patterns with dynamic analytical charts to help you maintain healthier social habits.

---

##  Key Features

* **👥 Smart Relationship Tracking & Automation:** Monitors interaction health using dynamic status badges (`On-Track`, `Almost-Due`, `Overdue`). It automatically calculates the days remaining based on your personalized interval goals and displays the exact upcoming due date.
* ** Advanced Activity Dropdown Timeline:** Keeps a centralized log of every communication. You can effortlessly filter the entire timeline using a sleek, customized dropdown box to view specific logs for Call, Text, or Video interactions.
* ** Dynamic Friendship Analytics:** Includes a dedicated statistics page powered by an interactive Donut/Pie Chart. The chart updates in real-time, visualizing your balance between different interaction types (Calls vs. Texts vs. Videos).

---

##  Technologies Used

This project leverages modern web development tools for a fast, responsive, and reliable user experience:

* **Frontend Library:** React.js (v18+)
* **Routing:** React Router DOM
* **Styling & UI:** Tailwind CSS & DaisyUI
* **State Management:** React Context API (for global timeline syncing)
* **Data Visualization:** Recharts (for dynamic analytics)
* **Icons:** Lucide React & React Icons
* **Notifications:** React Hot Toast
